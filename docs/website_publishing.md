# Website publishing status

The maintained configuration publishes control and status over park MQTT and presents status on the HA dashboards and physical signs. The checked-in configuration contains no website publisher, public endpoint, destination URL or delivery acknowledgement. A sign update therefore provides no confirmation that the public website changed.

For an extension or weather closure, verify the physical sign wording and use the existing website editor or communications process separately if a website notice is required. Confirm the public page directly. Keep scheduled closing time, active admission decisions and weather closure distinct: a passed deadline can coexist with a queue still being admitted.
